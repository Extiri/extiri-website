The release route

The checks that keep the build, metadata, review materials, and submission aligned.

  1. Bump version numbersSet the marketing version and build number.
  2. Verify production endpointsCheck API URLs, flags, and analytics keys.
  3. Strip debug toolsRemove developer-only UI and logging.
  4. Check Privacy ManifestConfirm APIs, tracking domains, and collected data.
  5. Run UI testsSmoke-test the critical paths.
  6. Archive on Release configBuild, sign, and upload the Release archive.
  7. Update release notesWrite a factual “What’s New” summary.
  8. Update Privacy Nutrition LabelsMatch App Privacy to the current build.
  9. Verify review credentialsConfirm the demo account and reviewer notes.
  10. Attach IAPs and subscriptionsSet products, pricing, and localization.
  11. Check screenshots and previewsMake sure media reflects this build.
  12. Confirm age ratingReview the current questionnaire.
  13. Select the processed buildAttach it to the App Store version.
  14. Configure phased releaseChoose the rollout deliberately.
  15. Review the submission summaryRead it as a reviewer would.
  16. SubmitSend the version to App Review.

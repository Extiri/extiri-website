DEEP COPY ARCHITECTURE

Blueprints vs. Executions. Immutable historical records.

When you instantiate a procedure, Airstrip creates a deep-copy snapshot of the master blueprint. Modifying the blueprint later never retroactively alters your execution history.

Master Blueprints

Define reusable procedure templates with step sequences, Markdown instructions, interactive payload actions, and estimated durations.

Deep-Copy Execution Runs

Launching a run creates an isolated snapshot. You always know: "What procedure did I actually execute?" rather than what the doc says today.

Dynamic Launch Variables

Inject variables such as {{version}} or {{environment}} at launch time to customize your runbook for every release.

FAQ

How is Airstrip different from Notion or Confluence?

Documentation tools store static knowledge that gets edited over time. Airstrip is the execution layer: it turns procedures into interactive runs, keeps you focused with a floating overlay, surfaces context automatically, and creates immutable execution logs for every run.

Is Airstrip an enterprise automation or incident platform?

No. Enterprise platforms like PagerDuty or Rootly focus on organizational incident routing and cloud orchestration. Airstrip is a lightweight, personal, local Mac tool built for the person actually executing the procedure on their machine.

Does Airstrip execute arbitrary shell commands automatically?

No. Airstrip does not autonomously alter your infrastructure without your knowledge. Steps contain interactive actions like Copy Text, Open URL, and Duration Timers so you can execute steps with full human-in-the-loop control.

How does Focus Mode work?

Focus Mode opens a compact, borderless floating window that stays pinned above applications like Xcode, VS Code, or terminal. You can mark steps as Done, Skip, or Fail using keyboard shortcuts without switching back to a documentation app.

What are Context Observers?

Airstrip monitors active window focus and browser domain names locally. When it detects a matching app (e.g., Xcode) or web domain (e.g., your staging environment), it displays a discreet banner offering to launch the relevant runbook.

What happens to past execution records when I modify a blueprint?

Nothing. Airstrip uses a deep-copy snapshot architecture. When a run is initiated, the blueprint is copied into an independent execution record. Updating the master template later will never alter past run history.

How do AI agents use Airstrip via Model Context Protocol (MCP)?

Airstrip exposes an MCP interface that AI coding tools (such as Claude Desktop or Cursor) can query. Your AI agent can inspect procedure steps, initiate runs, and follow defined runbook steps with full human oversight.

Does Airstrip work offline?

Yes. Airstrip is a native macOS application that operates 100% offline. Your runbooks and execution history reside on your Mac.

Does it sync across Macs via iCloud?

Yes. Built natively for Apple platforms, Airstrip syncs your blueprints, active runs, and contextual observer rules seamlessly via iCloud.

Is there a free trial?

Yes. Airstrip is available on the Mac App Store with a 14-day free trial so you can test executable runbooks before subscribing.
